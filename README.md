**Quantum Kernel Based Transient Stability Assessment of Power Systems and Its Implementation in NISQ Environment**
This repo contains the code for the IEEE paper where we implemented a quantum machine-learning approach for transient stability assessment (TSA) using Quantum Embedded Kernels (QEKs). The method maps power system features into a high-dimensional Hilbert space using a variational quantum circuit. The circuit parameters are optimized via Kernel Target Alignment (KTA) to improve classification performance.
We experimented on both noiseless simulators and NISQ noisy environments.

Full paper: https://ieeexplore.ieee.org/document/10825774
